## ⚡ Installation Ultra-Rapide

### Lock Screen Widget (5 min)

1. Ouvrir Xcode
2. Ajouter fichiers aux targets
3. Configurer URL Scheme `hourglass://`
4. Ajouter `.handleDeepLinks()` dans app
5. Build & Run

**Détails ici :**
```bash
open "/Users/corentinsoula/Desktop/Hourglass 4/LOCK_SCREEN_QUICK_START.md"
```

### Ajouter sur iPhone (2 min)

1. Verrouiller iPhone
2. Long press écran verrouillé
3. "Personnaliser" → Écran verrouillé
4. Tap zone widgets
5. Chercher "Hourglass"
6. OK → Fait ! 🎉
