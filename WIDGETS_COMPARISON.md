# 📱 Comparaison : Home Screen vs Lock Screen Widget

## 🎯 Deux Types de Widgets

Vous avez maintenant **2 widgets différents** :

### 1️⃣ Home Screen Widget (Écran d'Accueil)
**Fichier :** `HourglassWidget.swift`
**Quand :** Quand le téléphone est **déverrouillé**

### 2️⃣ Lock Screen Widget (Écran Verrouillé) ⭐
**Fichier :** `LockScreenWidget.swift`
**Quand :** Quand le téléphone est **verrouillé**

---

## 📊 Comparaison Détaillée

| Critère | Home Screen | Lock Screen ⭐ |
|---------|-------------|----------------|
| **Visibilité** | Moyenne (10-20/jour) | **Haute (50-100/jour)** |
| **Friction** | Déverrouiller + swipe | **Juste déverrouiller** |
| **Informations** | Beaucoup (stats, grains, etc.) | **Essentielles (objectifs)** |
| **Action rapide** | Non | **Oui (tap → caméra)** |
| **Tailles** | Small/Medium/Large | Circular/Rectangular/Inline |
| **Addiction** | Bonne | **Excellente** |
| **iOS requis** | 16.0+ | 16.0+ |

---

## 🔥 Recommandation : Lock Screen Widget

**Pourquoi le Lock Screen est meilleur pour votre cas :**

### ✅ Avantages du Lock Screen

1. **Visibilité maximale**
   - Tu vois tes objectifs **à chaque déverrouillage**
   - Moyenne : 50-100 fois par jour
   - Rappel constant = impossible d'oublier

2. **Action ultra-rapide**
   - Tap sur le widget → Caméra directement
   - Pas besoin d'ouvrir l'app manuellement
   - Validation en 10 secondes

3. **Pression psychologique**
   - Countdown visible en permanence
   - Rouge si < 1h → Urgence
   - Culpabilité subtile si non validé

4. **Friction minimale**
   - Pas besoin de swipe entre les pages
   - Directement visible au déverrouillage
   - Toujours au même endroit

### 🤔 Inconvénients du Lock Screen

- Moins d'infos affichables (contraintes Apple)
- Pas de graphiques complexes
- Design plus sobre

## 💡 Recommandation d'Usage

**Lock Screen pour :**

**Pour qui :**

- Friction plus élevée
- Risque d'oublis

**Pour qui :**
- Utilisateurs déjà engagés
- Pas besoin de rappels constants
- Préfèrent les stats aux actions
